# 四水箱明文 plant 基线（Issue #73）

本场景只建立二输入二输出、四状态的**线性数学 plant**。参数唯一配置为
[`configs/quadruple_tank_plant.yaml`](../configs/quadruple_tank_plant.yaml)，由
`load_quadruple_tank_contract` 加载并严格校验；运行时从物理参数派生矩阵，配置不保存第二份矩阵。
它不包含 observer、控制器、参考阶跃、泵饱和、安全执行或 Fig. 4。

Issue #75 的安全闭环与 Fig. 4 接入见本文末尾及
[`docs/lan_continuous.md`](lan_continuous.md)；本段 #73 plant 定义仍是唯一物理来源。

## 来源与声明等级

| 项 | 数值、单位 | 来源与性质 |
| --- | --- | --- |
| 罐截面 `A₁..A₄` | `(28,32,28,32) cm²` | [Johansson (2000), p.457 参数表](https://people.kth.se/~kallej/papers/quadtank_ieeecst00.pdf)，印刷物理参数 |
| 出水孔截面 `a₁..a₄` | `(0.071,0.057,0.071,0.057) cm²` | Johansson p.457 参数表，印刷物理参数 |
| 泵流量系数 `k₁,k₂` | `(3.33,3.35) cm³/(V·s)` | Johansson p.457，最低相位 `P₋` 参数；与 3 V 工作电压不同 |
| 传感器增益 `k_c`、重力 `g` | `0.50 V/cm`、`981 cm/s²` | Johansson p.457 参数表 |
| 工作高度 `h⁰`、泵电压 `v⁰`、阀分流 `γ` | `(12.4,12.7,1.8,1.4) cm`、`(3,3) V`、`(0.7,0.6)` | [Teranishi–Tanaka v3 Sec. VII](https://arxiv.org/html/2503.02176v3)，直接给出；与 Johansson `P₋` 点相同 |
| 采样周期 `T_s`、初态 `xₚ(0)` | `0.5 s`、`(10,10,10,10)ᵀ` | Teranishi–Tanaka v3 Sec. VII，直接给出数值 |
| 偏差状态、ZOH | `x=h−h⁰`、`u=v−v⁰`、输入每 `0.5 s` 保持常值 | Johansson p.458 式 (2) 的坐标与本项目的**离散化选择**；控制论文未印出离散 `Aₚ/Bₚ/Cₚ` 或离散化算法 |
| `xₚ(0)` 坐标解释 | `(10,10,10,10) cm` 作为偏差状态 | 本项目明确假设；控制论文没有消除绝对高度/偏差高度歧义 |

Johansson p.457 式 (1) 的非线性水量平衡在每个罐包含排水
`−aᵢ√(2ghᵢ)/Aᵢ`；罐 1 接受罐 3 排水和 `γ₁k₁v₁/A₁`，罐 2 接受罐 4
排水和 `γ₂k₂v₂/A₂`；罐 3 接受 `(1−γ₂)k₂v₂/A₃`，罐 4 接受
`(1−γ₁)k₁v₁/A₄`。仅用其 p.458 式 (2)–(3) 在给定工作点的线性化：

`Tᵢ=(Aᵢ/aᵢ)√(2hᵢ⁰/g)`，`Fᵢᵢ=−1/Tᵢ`，仅有
`F₁₃=A₃/(A₁T₃)`、`F₂₄=A₄/(A₂T₄)` 两个非零非对角项。
`G` 的四行依次是 `(γ₁k₁/A₁,0)`、`(0,γ₂k₂/A₂)`、
`(0,(1−γ₂)k₂/A₃)`、`((1−γ₁)k₁/A₄,0)`。
`C=[[k_c,0,0,0],[0,k_c,0,0]]`，`Dₚ=0₂ₓ₂`。
`F/Aₚ` 为 `4×4`，`G/Bₚ` 为 `4×2`，`C/Cₚ` 为 `2×4`。

从 `exp([[F,G],[0,0]]T_s)` 的左上角和右上角分别取得 `Aₚ` 与 `Bₚ`。
由此 `x(k+1)=Aₚx(k)+Bₚu(k)`、`y(k)=Cₚx(k)`；状态是 cm 高度偏差，
输入是 V 泵电压偏差，输出是 V 测量偏差。物理量可按 `h=h⁰+x`、`v=v⁰+u`
解释，但实现不对输入裁剪。Johansson 印刷参数经舍入后，工作点代入原非线性
式未必严格平衡；这里依照印刷线性式不加入仿射残差。

## 固定明文基线与时间索引

`tests/test_quadruple_tank_plant.py` 固定独立计算的 `F/G/Aₚ/Bₚ` 与轨迹数值。
基准从上述印刷式独立构建 `F/G/C`，用 SciPy `cont2discrete(..., method="zoh")`
一次计算并把结果作为测试常量保存；测试不调用生产 builder 生成 expected。
零偏差输入时：

| `k` | `t_k` (s) | 更新前 `y_k` (V) |
| ---: | ---: | --- |
| 0 | 0 | `(5, 5)` |
| 1 | 0.5 | `(5.063433803466769, 5.054834705896797)` |
| 2 | 1.0 | `(5.124227469964732, 5.108003930914347)` |
| 3 | 1.5 | `(5.182446215371368, 5.159539398457492)` |
| 4 | 2.0 | `(5.238153821164452, 5.209472284345622)` |

测试还固定两路单泵首步脉冲后的跨通道响应和终点 `k=5`，防止泵路/符号
错接。通用仿真按 `reference → 更新前 output → controller_input → runtime.step
→ apply_control → plant.step` 调用。记录 `N` 行对应 `k=0..N−1`；推进后终点
`x_N` 不属于第 `N−1` 行。adapter 返回两路零值 `unused_zero` 占位（无量纲），
直接将测量 `y` 传给未来 observer，将 raw `u` 原样复制给 plant；它们不是论文
参考轨迹或控制器。测试用局部脉冲 runtime 验证时序，不声称复现论文闭环。

如果把论文的 `xₚ(0)=10` 解释成**物理高度**，初始偏差将为 `10−h⁰`，
初始输出是 `(-1.2,-1.35) V`，不是本基线。当前偏差解释给出罐 1/2 的
物理初高 `22.4/22.7 cm`，超过 Johansson 所述约 `20 cm` 实验罐高度；
因此本模型只主张可复核的**线性数学轨迹**，不主张原硬件可实现该初态、
作者实际采用 ZOH、或与作者未公开的离散矩阵逐项相同。

## 四水箱 observer 明文接入（Issue #74）

[`configs/quadruple_tank_observer.yaml`](../configs/quadruple_tank_observer.yaml) 是
[Teranishi–Tanaka v3 §VII](https://arxiv.org/html/2503.02176v3) 的**印刷控制器**
`A/B/C/D/x0` 唯一可执行来源。`load_quadruple_tank_observer_spec` 严格检查来源标识、
字段、重复 YAML 键、shape、实数与有限性，转为统一 `float64` 的只读
`ControllerSpec`；不在源码另存矩阵，也不复制 #73 的物理参数。印刷的十进制小数
在加载后成为 binary64 近似；`scale_metadata=None`，此处没有按 `ell` 编码、取整、
模数或 Trunc。原文没有公开舍入前的精确 `F/L` 及完整整定过程，所以不能把印刷
小数称为作者的未量化增益。#75 如需定点化，应从该印刷值按当时确定的 `ell`
和现有定点契约逐元素转换，不能在此保存多套量化矩阵。

论文把 `B=L` 排成 `2×4` 后整体转置；配置保存实际 `4×2` 的 `B`。
`C=F` 为 `2×4`，`D=0₂ₓ₂`，observer 初态 `x_c,0=0₄`。输入是 #73 adapter
传入的 `y=(y₁,y₂)` 测量**电压偏差**（V），输出是施加给 plant 的
`u=(u₁,u₂)` 泵电压偏差（V）；零 reference 仍只是未用占位。`x_c∈R⁴` 按
与 #73 的 `x_p=(h₁,h₂,h₃,h₄)−h⁰` 同一高度偏差坐标解释（cm）。因此
`A:4×4` 无量纲、`B:4×2` 为 cm/V、`C:2×4` 为 V/cm、`D:2×2` 为 V/V。
采样周期来自 #73 的 plant 配置，`T_s=0.5 s`，observer 配置不重复保存它。

每步用**更新前**的 `x_c,k` 计算 `u_k=Cx_c,k+Dy_k`，再执行
`x_c,k+1=Ax_c,k+By_k`，最后 plant 执行 `x_p,k+1=A_p x_p,k+B_p u_k`。
初始 `x_p,0=(10,10,10,10) cm`、`y₀=(5,5) V`、`x_c,0=0`，所以
`u₀=(0,0) V`、`x_c,1=(3.91838075,3.92318725,1.51153565,1.53594970) cm`。
[`tests/test_quadruple_tank_observer.py`](../tests/test_quadruple_tank_observer.py)
用从论文独立转录的字面量和独立闭环递推值检验印刷矩阵、`k=0..4` 的
`y/x_c/u`、通用明文 runtime 和仿真时序。

以本项目 #73 ZOH 矩阵作关系检查，逐项
`R=A−(A_p+B_p C−B C_p)` 约为：

```text
[[-0.00000097, +0.00003429, -0.00002480, -0.00001295],
 [+0.00001153, +0.00002517, +0.00000310, +0.00001971],
 [-0.00000870, -0.00002706, -0.00000053, -0.00000599],
 [-0.00001999, -0.00001105, -0.00000721, +0.00002108]]
```

`max|R|≈3.42918×10⁻⁵`。该非零残差与印刷小数精度及未公开建模细节相容，
不能据此证明作者采用 ZOH，也不应为消除残差修改印刷值或 plant。
从 #73 plant 和本控制器装配论文式 (3) 的
`Φ=[[A_p+B_p D C_p, B_p C],[B C_p, A]]`（`8×8`），用现有
`check_discrete_schur_stability` 对特征值、归一化特征向量残差和条件数进行诊断：
本模型的 `status=stable`、谱半径约 `0.9921134672`；矩阵条件数约 `2.1664`，
特征向量条件数约 `56.1681`，最大归一化特征对残差约 `1.14×10⁻¹⁵`。
这是当前 ZOH 口径的明文
数值交叉核查，不是任意模型的常数，也不是安全协议的范围证明。

## 连续安全数值接入（Issue #75）

`scenarios/quadruple_tank/secure_experiment.py` 从本页两份 canonical 配置装配
互不共享状态的 ideal/secure 分支，并用独立的 `8×8 Φ^k` 验证 51 步明文基线。
profile 的两路测量界 `[256,256] V` 通过耦合包络逐步证明：同时向外界定两支
plant/observer、binary64 矩阵运算和每行 Trunc 的至多 1 payload 误差，再由
Client 用精确整数复核每步 state/output accumulator、Protocol 2 κ 和中心化模范围。
四种精度下保守测量上界约为 `[162.77,134.23] V`。这些界只证明冻结的线性
模拟 plant，不是物理水箱测量界或实机网络安全证明。

正式四次本机三进程 run 和只读 Fig. 4 图在 `results/quadruple_tank_lan/` 与
`results/quadruple_tank_fig4/`。每个 run 的 `metadata.json` 记录 51 次双提交、
1836 次乘法和 204 次 Trunc；Fig. 4 清单绑定来源摘要、四个不同 session、
每点两路有符号控制误差的 L2 范数、零样本及 binary64 ULP。四种精度的最大
范数均低于 `2^-10 V`，但 56 位差异已接近数值分辨率，不能视为精确零或
作者论文原始 Fig. 4 逐点数据。运行和复验命令见 `docs/lan_continuous.md`。
