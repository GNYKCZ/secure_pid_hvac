# 四水箱明文 plant 基线（Issue #73）

本场景只建立二输入二输出、四状态的**线性数学 plant**。参数唯一配置为
[`configs/quadruple_tank_plant.yaml`](../configs/quadruple_tank_plant.yaml)，由
`load_quadruple_tank_contract` 加载并严格校验；运行时从物理参数派生矩阵，配置不保存第二份矩阵。
它不包含 observer、控制器、参考阶跃、泵饱和、安全执行或 Fig. 4。

## 来源与声明等级

| 项 | 数值、单位 | 来源与性质 |
| --- | --- | --- |
| 罐截面 `A₁..A₄` | `(28,32,28,32) cm²` | [Johansson (2000), p.457 参数表](https://people.kth.se/~kallej/papers/quadtank_ieeecst00.pdf)，印刷物理参数 |
| 出水孔截面 `a₁..a₄` | `(0.071,0.057,0.071,0.057) cm²` | Johansson p.457 参数表，印刷物理参数 |
| 泵流量系数 `k₁,k₂` | `(3.33,3.35) cm³/(V·s)` | Johansson p.457，最低相位 `P₋` 参数；与 3 V 工作电压不同 |
| 传感器增益 `k_c`、重力 `g` | `0.50 V/cm`、`981 cm/s²` | Johansson p.457 参数表 |
| 工作高度 `h⁰`、泵电压 `v⁰`、阀分流 `γ` | `(12.4,12.7,1.8,1.4) cm`、`(3,3) V`、`(0.7,0.6)` | [Teranishi–Tanaka v3 Sec. VII](https://arxiv.org/html/2503.02176v3)，直接给出；与 Johansson `P₋` 点相同 |
| 采样周期 `T_s`、初态 `xₚ(0)` | `0.5 s`、`(10,10,10,10)ᵀ` | Teranishi–Tanaka v3 Sec. VII，直接给出数值 |
| 偏差状态、ZOH | `x=h−h⁰`、`u=v−v⁰`、输入每 `0.5 s` 保持常值 | Johansson p.458 式 (2) 的坐标与本项目的**离散化选择**；控制论文未印出离散 `Aₚ/Bₚ/Cₚ` 或离散化算法 |
| `xₚ(0)` 坐标解释 | `(10,10,10,10) cm` 作为偏差状态 | 本项目明确假设；控制论文没有消除绝对高度/偏差高度歧义 |

Johansson p.457 式 (1) 的非线性水量平衡在每个罐包含排水
`−aᵢ√(2ghᵢ)/Aᵢ`；罐 1 接受罐 3 排水和 `γ₁k₁v₁/A₁`，罐 2 接受罐 4
排水和 `γ₂k₂v₂/A₂`；罐 3 接受 `(1−γ₂)k₂v₂/A₃`，罐 4 接受
`(1−γ₁)k₁v₁/A₄`。仅用其 p.458 式 (2)–(3) 在给定工作点的线性化：

`Tᵢ=(Aᵢ/aᵢ)√(2hᵢ⁰/g)`，`Fᵢᵢ=−1/Tᵢ`，仅有
`F₁₃=A₃/(A₁T₃)`、`F₂₄=A₄/(A₂T₄)` 两个非零非对角项。
`G` 的四行依次是 `(γ₁k₁/A₁,0)`、`(0,γ₂k₂/A₂)`、
`(0,(1−γ₂)k₂/A₃)`、`((1−γ₁)k₁/A₄,0)`。
`C=[[k_c,0,0,0],[0,k_c,0,0]]`，`Dₚ=0₂ₓ₂`。
`F/Aₚ` 为 `4×4`，`G/Bₚ` 为 `4×2`，`C/Cₚ` 为 `2×4`。

从 `exp([[F,G],[0,0]]T_s)` 的左上角和右上角分别取得 `Aₚ` 与 `Bₚ`。
由此 `x(k+1)=Aₚx(k)+Bₚu(k)`、`y(k)=Cₚx(k)`；状态是 cm 高度偏差，
输入是 V 泵电压偏差，输出是 V 测量偏差。物理量可按 `h=h⁰+x`、`v=v⁰+u`
解释，但实现不对输入裁剪。Johansson 印刷参数经舍入后，工作点代入原非线性
式未必严格平衡；这里依照印刷线性式不加入仿射残差。

## 固定明文基线与时间索引

`tests/test_quadruple_tank_plant.py` 固定独立计算的 `F/G/Aₚ/Bₚ` 与轨迹数值。
基准从上述印刷式独立构建 `F/G/C`，用 SciPy `cont2discrete(..., method="zoh")`
一次计算并把结果作为测试常量保存；测试不调用生产 builder 生成 expected。
零偏差输入时：

| `k` | `t_k` (s) | 更新前 `y_k` (V) |
| ---: | ---: | --- |
| 0 | 0 | `(5, 5)` |
| 1 | 0.5 | `(5.063433803466769, 5.054834705896797)` |
| 2 | 1.0 | `(5.124227469964732, 5.108003930914347)` |
| 3 | 1.5 | `(5.182446215371368, 5.159539398457492)` |
| 4 | 2.0 | `(5.238153821164452, 5.209472284345622)` |

测试还固定两路单泵首步脉冲后的跨通道响应和终点 `k=5`，防止泵路/符号
错接。通用仿真按 `reference → 更新前 output → controller_input → runtime.step
→ apply_control → plant.step` 调用。记录 `N` 行对应 `k=0..N−1`；推进后终点
`x_N` 不属于第 `N−1` 行。adapter 返回两路零值 `unused_zero` 占位（无量纲），
直接将测量 `y` 传给未来 observer，将 raw `u` 原样复制给 plant；它们不是论文
参考轨迹或控制器。测试用局部脉冲 runtime 验证时序，不声称复现论文闭环。

如果把论文的 `xₚ(0)=10` 解释成**物理高度**，初始偏差将为 `10−h⁰`，
初始输出是 `(-1.2,-1.35) V`，不是本基线。当前偏差解释给出罐 1/2 的
物理初高 `22.4/22.7 cm`，超过 Johansson 所述约 `20 cm` 实验罐高度；
因此本模型只主张可复核的**线性数学轨迹**，不主张原硬件可实现该初态、
作者实际采用 ZOH、或与作者未公开的离散矩阵逐项相同。

#74 可复用此配置、矩阵与测量映射接入 observer；#75 才讨论安全协议和 Fig. 4。
